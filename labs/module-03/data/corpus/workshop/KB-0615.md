# Fault code FC-BAT-2201: HV battery cell temperature spread high

## Safety first

Work on the high-voltage (HV) system only if you hold HV qualification level 2 (HV2) and the
vehicle is de-energised following the workshop HV safety procedure. Reading fault codes and
temperatures with DiagLink needs no HV qualification.

## What the code means

The battery management system measured a temperature difference of more than **8 K** between
the hottest and the coldest cell module of one battery pack. Above **12 K** the system limits
DC charging power to 50 kW to protect the cells.

## Diagnosis

1. Check the battery management software version. Below BMS-3.2.1, install the update from
   **TSB-2026-047** first; it fixes most cases that appear during DC charging.
2. Read the module temperatures in DiagLink ("HV system > battery packs > module temperatures")
   and note which pack and module are out of line.
3. Check the battery coolant flow. A low flow also raises **FC-EAX-1310**; see **KB-0622**.
4. If one module stays hotter than the others after the update and with normal coolant flow,
   do not open the pack. Open a technical case with After-Sales Technical Support and attach
   the DiagLink session report.

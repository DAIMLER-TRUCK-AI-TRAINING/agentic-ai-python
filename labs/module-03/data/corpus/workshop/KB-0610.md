# Fault code FC-ADB-0412: AdBlue dosing pressure low (diagnosis)

## What the code means

The SCR system measured an AdBlue dosing pressure below **3.5 bar** for more than 60 seconds
while dosing was requested. The nominal dosing pressure is 5.0 bar ± 0.3 bar.

## Diagnosis, in this order

1. **AdBlue quality.** Take a sample from the tank and measure it with a refractometer. The
   urea concentration must be between 31.8 % and 33.2 %. Diluted or contaminated AdBlue is the
   most common cause; drain and refill if it is out of range.
2. **Line heater.** Measure the resistance of the dosing line heater: 2.5 to 3.5 ohm at 20 °C.
3. **Filter.** Inspect the AdBlue pump filter for crystals or debris and replace it if blocked.
4. **Dosing pressure test.** Run the DiagLink routine "SCR dosing test" and read the pressure.
5. **Dosing valve.** If the pressure is still low, check the valve nozzle for crystals.

LH-40 tractors with the DTE-13 engine built in weeks 01 to 13 of 2026 have a known dosing valve
issue: follow **TSB-2026-031** instead of cleaning the valve.

## After the repair

Clear the fault memory, run the dosing test again, and test-drive for at least 20 minutes so
the system can confirm the repair. Engine power returns to normal once the fault is inactive.

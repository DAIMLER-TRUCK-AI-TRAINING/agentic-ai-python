# ED-26 battery management software update for the coolant pump control

## Affected vehicles

ED-26 battery-electric distribution trucks with battery management software (BMS) older than
**BMS-3.2.1**. Check the installed version in DiagLink under "HV system > BMS".

## Symptoms

- Fault code **FC-EAX-1310** (eAxle coolant flow low) is stored at outside temperatures below
  −5 °C, although the coolant level and the pump are in order.
- During DC fast charging the fault code **FC-BAT-2201** (HV battery cell temperature spread
  high) appears and the charging power drops.

## Cause

The old software starts the coolant pump at a low speed after a cold start, and it reacts too
late to the temperature rise in the battery modules during DC charging.

## Repair

1. Connect DiagLink and a battery charger to keep the 24 V supply above 26 V.
2. Install battery management software **BMS-3.2.1**. The installation takes about 25 minutes.
3. Run the DiagLink routine "EAX coolant bleed" afterwards.
4. Clear the fault memory and run a DC charging session of at least 10 minutes.

High-voltage covers stay closed for this update; no HV qualification is needed for it.

## Warranty

Covered by warranty for all affected vehicles. Claim with labour code **LC-BMS-47**
(0.6 hours).

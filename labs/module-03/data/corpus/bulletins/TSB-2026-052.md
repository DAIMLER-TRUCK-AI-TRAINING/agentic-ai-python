# TCU-5 over-the-air update stalls at 60 percent in workshop halls

## Affected vehicles

All model series with the TCU-5 telematics control unit (LH-40, ED-26 and CT-33 built since
2025).

## Symptom

An over-the-air (OTA) software update started from the Fleet Insight portal or from DiagLink
stops at **60 %**. The instrument cluster shows "Update in progress" for hours. The fault code
**FC-TCU-0901** (no backend connection) may follow.

## Cause

At 60 % the TCU-5 verifies the signature of the new software package. The check needs the
correct time. Inside workshop halls the unit often has no satellite (GNSS) fix, and after a
battery disconnect its clock can be wrong, so the verification never completes.

## Repair

1. Do **not** disconnect the batteries or power-cycle the vehicle while the update is
   pending: the unit could be left without a valid software partition.
2. Move the vehicle outdoors until the TCU-5 has a GNSS fix (about 5 minutes), or set the
   time with the DiagLink function "TCU time sync".
3. Restart the update from DiagLink. The remaining 40 % takes about 15 minutes.
4. If the update fails three times, open a technical case with After-Sales Technical Support
   and attach the TCU log.

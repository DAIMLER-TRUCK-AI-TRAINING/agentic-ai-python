# Vehicle software updates and cybersecurity

## §1 Purpose

This policy sets the rules for installing software on vehicles. It implements the company's
software update management system and cybersecurity management system under UN Regulations
No. 156 and No. 155.

## §2 Signed software only

Only software packages signed by the company may be installed on a vehicle, whether over the
air or in the workshop. DiagLink checks the signature before every installation.

## §3 Installation rules

- Over-the-air updates install only when the vehicle is parked with the ignition off.
- Workshops install software only through DiagLink. USB sticks and third-party tools are not
  allowed.
- Never interrupt an installation by disconnecting the batteries.

## §4 Reporting

Report any suspected tampering with vehicle software, or any unsigned software found on a
vehicle, to the **Vehicle Security Operations Centre (VSOC) within 24 hours**. Do not try to
remove the software yourself; the VSOC secures the evidence first.

## §5 Records

Every software installation is logged with the vehicle identification number, the package
version and the installer, and the log is kept for 10 years.

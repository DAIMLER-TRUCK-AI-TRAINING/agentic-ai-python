# AdBlue dosing valve crystallisation on LH-40 tractors with DTE-13 engines

## Affected vehicles

LH-40 long-haul tractors with the DTE-13 diesel engine, EU specification, built from
calendar week 01/2026 to calendar week 13/2026. Vehicles built from week 14/2026 have the
revised dosing valve fitted at the factory.

## Symptom

The driver sees the yellow AdBlue warning lamp and fault code **FC-ADB-0412** (AdBlue dosing
pressure low) is stored. It appears mostly after short-distance work with long idle periods.
If the fault stays active, engine power is reduced in two steps: first to 75% torque, then,
after the next engine stop, to a limp mode of 20 km/h.

## Cause

Urea crystals build up in the nozzle of the dosing valve when the exhaust temperature stays low.
The crystals restrict the flow, so the dosing pressure drops below the 3.5 bar limit.

## Repair

1. Read the fault memory with DiagLink and confirm FC-ADB-0412 is the only aftertreatment fault.
2. Replace the dosing valve with part number **PN 47-0118-334** (revised nozzle geometry).
3. Replace the dosing line heater with part number **PN 47-0118-341**.
4. Update the engine control software to version **E13-7.4.2** or later.
5. Run the DiagLink routine "SCR dosing test" and confirm 5.0 bar ± 0.3 bar.

Do not clean and refit the old valve: crystallisation returns within weeks.

## Warranty

Repairs under this bulletin are covered by warranty for affected vehicles. Claim with labour
code **LC-ADB-31** (2.1 hours) through the Dealer Workshop Portal and attach the DiagLink
session report.

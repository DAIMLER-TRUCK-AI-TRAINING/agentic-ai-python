# Over-the-air software updates for your truck

Connected trucks receive software updates over the air (OTA), so many improvements arrive
without a workshop visit.

## How an update works

1. Fleet Insight shows a new update for a truck and the fleet manager approves it, or it is
   approved automatically if you chose that setting.
2. The truck downloads the update while it is driven. Driving is not affected.
3. The update installs only when the truck is **parked with the ignition off**. The installation
   takes **up to 35 minutes**, and the truck cannot be started during that time.

## What the driver sees

The instrument cluster asks for confirmation before the installation starts and shows the
progress. Do not disconnect the batteries during an installation.

## If an update does not finish

If the progress does not change for more than an hour, leave the truck parked outdoors with
the ignition off and try again later. If it still does not finish, contact your dealer. Your
truck stays drivable on its current software until the update completes.

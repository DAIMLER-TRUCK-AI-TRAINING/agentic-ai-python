# DiagLink cannot find the VCI-3 interface after a Windows update

## Symptom

After a Windows update on the diagnostic laptop, DiagLink shows "No vehicle communication
interface found". The VCI-3 status LED is green, so the interface itself has power.

## Cause

Some Windows updates replace the USB driver of the VCI-3 with a generic driver that DiagLink
cannot use.

## Resolution

1. Close DiagLink.
2. Open "DiagLink Tools > Driver setup" and reinstall the **VCI-3 driver version 3.8** or later.
3. Connect the VCI-3 with the supplied USB-C cable directly to the laptop, not through a hub
   or a docking station.
4. Restart the laptop and start DiagLink again.

If the interface is still not found, test it on a second laptop. If it fails there too, raise
an incident with the Service Desk so the VCI-3 can be replaced; include its serial number.

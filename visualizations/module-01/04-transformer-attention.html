Topic 4

Attention: every token can look at every other token

Attention lets “it” pull meaning from “packet” or “router”, which is why transformers resolve references so well, and why their cost grows with the square of the input length. Click a token to see where it attends, flip the last word between malformed and overloaded, then apply the decoder’s causal mask and watch what “it” can no longer see.

Query, key, value

Attention(Q, K, V) = softmax(Q·Kᵀ / √dₖ) · V

Each token emits a query (what it is looking for), a key (what it offers) and a value (the information it passes on). Query–key scores, scaled and normalised by softmax, become the weights in each heatmap row (every row sums to 1). The token’s new representation is the weighted mix of values. Many heads run in parallel, each learning a different pattern, and dozens of layers are stacked. The three heads here are illustrative, modelled on patterns researchers have found in real models.

Encoder, decoder, encoder–decoder

ArchitectureAttentionExample modelsTypical enterprise use
Encoder-onlyBidirectional self-attention: every token sees the whole inputBERT, RoBERTa; Sentence Transformers such as all-MiniLM-L6-v2Embeddings, NER, classification (Topics 2 and 6)
Decoder-onlyCausal self-attention: each token sees only earlier tokensOpenAI GPT and Anthropic Claude families; most open-weights LLMsGeneration, chat, tool-using agents
Encoder–decoderEncoder self-attention, decoder causal self-attention, plus cross-attention from decoder to encoderThe original Transformer (2017), T5, BART, MarianMTTranslation, summarisation
Engineering takeaway: full self-attention computes n² scores per head per layer. Doubling a prompt from 4,096 to 8,192 tokens quadruples that work (16.8 M → 67.1 M scores). Kernels such as FlashAttention cut memory traffic, but long prompts still cost more time and money, so send what the task needs, not everything you have (Topic 5).
Common trap: reading attention weights as the model’s explanation. A heatmap shows one head in one layer; the decision emerges from many heads, layers and feed-forward blocks. Use attention to build intuition, and use evals and tracing (Module 5) to explain behaviour.

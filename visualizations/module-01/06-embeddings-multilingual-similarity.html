Topic 6

Distance means meaning, if the model can read the language

An embedding model turns each ticket into a vector, and cosine similarity tells you how close two meanings are. A multilingual model puts “VPN keeps disconnecting” next to “VPN trennt ständig die Verbindung”; an English-only model groups tickets by language instead. Click a ticket, switch models, colour by language and move the duplicate threshold.

From text to vectors in a few lines

Sentence Transformers (local)

from sentence_transformers import SentenceTransformer

model = SentenceTransformer(
    "paraphrase-multilingual-MiniLM-L12-v2")   # 384 dims
emb = model.encode(tickets, normalize_embeddings=True)
scores = model.similarity(emb, emb)            # cosine

OpenAI embeddings (API)

from openai import OpenAI

client = OpenAI()
resp = client.embeddings.create(
    model="text-embedding-3-small", input=tickets)
vectors = [d.embedding for d in resp.data]   # 1536 dims

Engineering takeaway: a threshold belongs to one model. Calibrate it on labelled ticket pairs, store the model name next to every vector, and when you switch models, re-embed the whole corpus. Vectors from two models live in different spaces, often with different dimensions, so their cosines are meaningless together.
Common trap: trusting a high score from a model that cannot read the language. With the English-only model, the German password ticket sits closest to the German printer ticket (0.74): shared language, not shared meaning. Test with every language your users write in before you pick a model.

Fine-tuning changes behaviour, not knowledge

Fine-tuning, RAG, prompt engineering and hybrids solve different problems. The framework decides on four questions the outline names (data availability, latency, cost and update frequency) plus two that settle most debates: what must change, and must the answer cite a source? Load each workshop scenario, read the canvas, then change one input at a time and watch the recommendation flip. Below the canvas, size a LoRA adapter against full fine-tuning.

    Fine-tuning methods (overview)
    
  
    
    
    
      
    MethodWhat it updatesCost and artefactUse it when
    
      
        
    Full fine-tuningEvery weightMost GPU memory; a full copy of the model per variantYou own the model, have lots of data and need the deepest change
    
        
    LoRA / PEFTSmall low-rank adapter matrices beside frozen weights (PEFT is the family; LoRA the most common member)A fraction of a per cent of the parameters; adapters of megabytes you can swap per taskThe default way to fine-tune open-weight models
    
        
    Instruction tuningEither of the above: it names the data (instruction → response pairs), not the methodDepends on the method underneathYou want a model to follow a task format reliably
    
        
    Hosted fine-tuningWhatever the provider exposes for the models it allowsUpload a JSONL file, get a new model ID; availability varies by provider and modelYou use a closed model and the provider offers tuning for it
    
          
    
    
  
    
  
    Engineering takeaway: work up the ladder and stop at the first rung that clears your evaluation bar:
    prompt engineering, then RAG, then fine-tuning, then a hybrid. Each rung adds data work, infrastructure and an evaluation cycle, so
    you need the eval set (Topic 6) before you can tell whether the next rung paid off.
    
  
    Common trap: fine-tuning to teach facts. The model learns that KB answers look a certain
    way and will produce that look for questions it has no facts for, with no source to check, frozen on training day and visible to
    every user. Put facts in retrieval; fine-tune for format, tone, vocabulary and narrow tasks.

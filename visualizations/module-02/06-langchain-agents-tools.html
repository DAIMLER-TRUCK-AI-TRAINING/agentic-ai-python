Topic 6

A chain runs the steps you wrote; an agent chooses the next one

LangChain gives you two shapes. An LCEL chain is a fixed pipeline you can test like any function. An agent built with create_agent is a loop where the model picks tools until it can answer. Send three operations questions through both, then add the Tavily key and enable code execution to see how the agent’s path, cost and trustworthiness change.

Outline vs current API: the outline’s “agent executors” are taught here as create_agent, which
    runs the same loop (model → tool calls → tool results → model) as a LangGraph graph. That gives you checkpointing, streaming and
    middleware for free, and it is the graph you extend in Module 4.

  
Common trap: reaching for an agent when a chain will do. Q1 needs the same query every time,
    and the chain answers it with one model call and no tool-selection risk. Use an agent only when the next step genuinely depends
    on the question, and then give it narrow, read-only tools.
